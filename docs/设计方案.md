# 词阶 WordStairs · 产品与技术设计方案

> 面向小学高年级至高中学生的英语单词 / 句子学习工具，覆盖听、说、读、写四项训练。
> 演示页：`demo/index.html`（单文件 HTML，双击即可打开）。
> **V1 正式版代码已落地**：`backend/`（FastAPI）与 `frontend/`（React + Vite + TS），启动方式见根目录 README。

---

## 一、产品定位

**名字**：词阶 WordStairs。「阶」取两重含义：词汇逐级拾阶而上；学段从小学、初中到高中逐级进阶。

**目标用户**

| 角色 | 场景 |
|---|---|
| 学生（核心，10–18 岁） | 每天 10–20 分钟：复习队列 + 专项练习，攒积分换奖励 |
| 家长 | 配置奖励、查看周报，不盯着孩子也能了解学习情况 |

**设计原则**

1. 进步可见：阶位、印章、正字计数，让「今天学了多少」一眼可见。
2. 反馈及时但不幼稚：没有卡通形象和音效轰炸，用批改红勾、盖章这类「学校里真实存在的奖励语言」。
3. 听说读写均衡：四种练习模式一一对应四项技能，错题自动回流。
4. 家长低介入：奖励规则家长定一次，日常运转不需要家长参与。

## 二、视觉设计规范（demo 页已实现）

设计母题取自中国学生最熟悉的**英语练习本**：四线三格、方格纸、钢笔蓝黑、批改红笔、印章。小学到高中都通用，精致而不低龄。

### 色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸面底色 | `#F6F8F5` | 冷调纸白，叠淡蓝方格纹 |
| 主文字（墨色） | `#213A5E` | 钢笔蓝黑 |
| 次要文字 | `#54677D` / `#8B9AAB` | |
| 批改红（唯一强调色） | `#C4382E` | 红勾、印章、积分、今日标记 |
| 四线格线 | `rgba(64,105,180,.34)` | 练习本蓝格线 |
| 正确 | `#2F7D5A` | 答题反馈用常规绿，与红区分 |
| 提醒 | `#B97A16` | 模糊 / 连击 / 积分价格 |

红色只用于「激励与批改」语义（印章、红勾、加分、今日），语义反馈（对 / 错）仍用绿 / 红，避免歧义。

### 字体

- 英文展示：Fraunces（衬线，回退 Georgia）——大词、例句、拼写格子。
- 中文界面：系统 sans（PingFang SC / 微软雅黑）。
- 音标与数字：IBM Plex Mono（回退 Consolas）。
- 印章与中文强调：楷体（KaiTi），呼应手写批改的质感。

### 标志性视觉元素

- **四线三格**：单词展示、拼写输入都落在真实四线格上（拼写时逐字入格，是产品记忆点）。
- **批改红勾**：答对时红笔大勾（SVG 描边动画）。
- **印章**：打卡、阶位、徽章全部是红印章，盖章入场动画。
- **正字计数**：今日进度用「正」字笔画累进（一笔 = 1 词）。
- **阶位楼梯**：等级进度画成上行台阶，当前阶标红。

### 布局与适配

- 桌面：左主栏（学习流）+ 右侧栏（打卡 / 任务 / 阶位 / 流水），信息密度前紧后松。
- 平板（≤1060px）：侧栏下移为两列流；书架与导入、印章与奖励各自并排转上下。
- 触控目标 ≥ 44px；键盘可达（拼写回车提交、听力 1–4 数字作答、空格翻卡）。
- 尊重 `prefers-reduced-motion`，动画全部可关。

## 三、功能设计

### 3.1 账户与登录

- 注册 / 登录：用户名 + 密码（bcrypt 哈希），JWT 无状态会话；支持「学生 / 家长」两种角色，一个家长可绑定多个学生。
- 家长端 V1 只做三件事：配奖励、看周报、处理兑换申请。

### 3.2 词库与导入

- 内置词书：人教 PEP、外研、译林等主流教材（小学至高考 3500），按单元组织；预置美音 / 英音音频。
- 导入（三种途径）：
  1. 上传 CSV / Excel（xlsx），第一列单词、第二列释义，可选音标、例句、例句翻译；
  2. 粘贴文本，一行一条，逗号 / Tab 分隔；
  3. 学习过程中自动收集：生词收藏、错题自动进「我的生词本」。
- 导入处理：去重（词库里已有的标记跳过）、缺音标的可选自动补全（后端查词典库）、缺音频的用 TTS 兜底。

### 3.3 学习引擎（间隔重复）

- 简化 SM-2：认识 → 间隔拉长（1 → 2 → 4 → 8 → 16 天…）；想了一下 → 明天再来；不认识 → 3 天后强制重现且计入错题。
- 每日任务量可配（默认新词 10 + 复习按队列，上限 30），完成后次日 7 点排好新队列。
- 四项技能错题各自回流：听错的进步听队列，拼错的进默写队列。

### 3.4 练习模式（对应听说读写）

| 模式 | 技能 | 玩法 | 判分 |
|---|---|---|---|
| 听音辨词 | 听 | 播放读音，四选一选释义 | 即时 |
| 拼写默写 | 写 | 看释义 + 音标，逐字母敲进四线格；可听发音、花积分买字母提示 | 逐字母反馈 |
| 句子重组 | 读 / 写 | 打乱例句词语，点选组句；组对后朗读全句 | 语序比对 |
| 跟读评分 | 说 | 播示范 → 麦克风跟读 → 相似度得分环 | 词 + 字符双重比对 |
| 智能混练 | 综合 | 按薄弱项加权抽题，四模式混合 | 同上 |

音频方案：服务端用 edge-tts 预生成 mp3 缓存（离线可用、口音可选）；浏览器 `speechSynthesis` 作兜底。跟读评分：前端 Web Speech API 识别（Chrome / Edge），正式版可接 Azure Pronunciation Assessment 提升准确度（可选付费增强，接口已预留）。

### 3.5 积分与激励

**获取**（后端结算，前端只展示）

| 行为 | 分值 |
|---|---|
| 学会一个单词 | +2 |
| 练习答对 | +2 |
| 连对每满 3 题 | +5 |
| 每日任务（3 项） | +10 ~ +20 / 项 |
| 当日队列清空 | +20 |
| 每周满勤 | +50 |
| 每日上限 | 300（防刷，重复内容降权） |

**阶位**：每 200 分一阶，共 50 阶；称号分段：拾词生（1–3）→ 词客（4–9）→ 词士（10–19）→ 词师（20–34）→ 词宗（35+）。

**印章（徽章）**：初阶之印、七日之约、晨读者、百词行、听风耳、无误手、造句工匠、拾级而上（登上第 10 阶）等，全部红印章造型。

**消费**：家长在奖励小铺自定义奖励（如「周末电影一场 800 分」），学生发起兑换 → 积分冻结 → 家长确认后生效。另有补签卡、主题皮肤等小额消耗。

### 3.6 统计与报告

- 学生端：今日 / 本周学习量、正确率、听说读写四维雷达、错题本。
- 家长周报：学习天数、用时、正确率变化、兑换记录，页面 + 可选邮件。

## 四、技术架构

```
┌────────────────────────────┐
│ 前端 React 18 + Vite + TS  │
│ TanStack Query + Zustand   │
│ 设计 tokens（对齐 demo 页） │
└──────────────┬─────────────┘
               │ HTTPS /api · JWT Bearer
┌──────────────▼─────────────┐
│ 后端 FastAPI + SQLAlchemy  │
│  ├ auth     登录 / JWT     │
│  ├ books    词书 / 词单     │
│  ├ import   CSV/xlsx 解析  │
│  ├ study    SM-2 队列调度   │
│  ├ practice 答题与判分      │
│  ├ points   积分流水（事务）│
│  ├ rewards  奖励与兑换      │
│  └ stats    报表聚合        │
└──────┬───────────┬─────────┘
       │           │
 SQLite(dev)    edge-tts 生成
 PostgreSQL     mp3 缓存目录
 (prod,同套ORM)  / 静态文件
```

要点：

- **前后端分离**：前端纯静态产物（nginx / Vercel 均可托管），后端只出 JSON API + 音频文件。
- **积分事务**：所有加分在后端事务内落 `points_ledger` 流水，前端展示与流水对账，杜绝刷分。
- **导入解析**：`pandas` / `openpyxl` 读表，服务端校验列映射，返回逐行解析结果（新增 / 重复）供前端预览确认。
- **部署**：docker-compose（web + api + db）；家用场景也可单机 `uvicorn` + 静态目录跑起来。

## 八、demo 页说明

`demo/index.html` 为纯前端单文件演示，可直接双击打开。页面为应用式框架：顶部菜单 + 四个页面（hash 路由 `#today / #practice / #library / #honors`）；桌面一行顶栏，中等宽度菜单只显示图标，窄屏菜单换到第二行完整显示。

- **今日学习（首页）**：问候与统计、正字计数、单词卡（点击 / 空格翻面、TTS 朗读、认识 / 想了一下 / 不认识推进队列、收尾盖章）、四个练习模式入口、打卡日历、今日任务、阶位；
- **专项练习**：听音辨词（自动播放 + 键盘 1–4、连击加成）、拼写默写（字母逐个落四线格、逐字母反馈、花积分买提示）、句子重组（点选组句、组对朗读）、跟读评分（Chrome / Edge 麦克风识别，其他浏览器优雅降级）；
- **词库与导入**：书架进度、粘贴文本导入解析（含去重预览，文件拖放为演示提示）；
- **印章与奖励**：印章墙、奖励小铺（兑换弹窗、真实扣分）、积分规则与流水。

数据均为演示假数据，正式版由 FastAPI 提供。
